Architecture

Built like a serious native tool

No remote server round-trips for your daily workflow. Every attendance click, schedule lookup, and metric recalculation executes locally on your machine.

Local SQLite Engine (<1 ms)

Runs in WAL mode with multi-core Tokio worker threads. Marking attendance or editing subjects updates dashboard rings, safe-bunk counts, and calendars instantaneously.

Private Drive AppData Sync

Link your own Google account to sync SHA-256 delta snapshots into your hidden appDataFolder. Zero third-party database ever sees your academic records.

Direct IPU ExamWeb Sync

Authenticates straight from your device to examweb.ggsipu.ac.in with manual CAPTCHA verification and client-side salted hashing, storing grades offline with PDF export.

BYOK AI Assistant

Includes an instant offline SQLite query assistant out of the box. Bring your own free Gemini or Groq API key in Settings — encrypted locally and never shared with anyone.

Chronological Timetable Radar

Groups consecutive lab blocks accurately, highlights active periods in real time, and lets you share or migrate schedules cleanly between devices.

Atomic Backups & Migration

Every restore or reset writes an automatic local safety snapshot first. Export clean canonical JSON anytime with full lossless round-trip verification.

Security Specification

Verifiable privacy by design

Built for students who care where their credentials and data live. Every claim below maps directly to audited code in the repository.

Hardware Secret Encryption

OAuth tokens and user-supplied Gemini / Groq API keys are encrypted at rest with Windows DPAPI (CryptProtectData, CurrentUser scope) with volatile memory zeroization before freeing plaintext buffers.

Backup & Database Hygiene

Local SQLite runs with PRAGMA secure_delete = ON, PRAGMA foreign_keys = ON, and 100% parameterized queries. Exported JSON backups and Drive snapshots never include API keys or OAuth tokens.

Strict WebView Sandbox

Enforces strict Content Security Policy (script-src 'self', object-src 'none', frame-ancestors 'none'), withGlobalTauri: false, and zero dangerouslySetInnerHTML sinks across the React UI.

Network & OAuth Guards

Uses PKCE S256 loopback OAuth with constant-time state verification, strict RFC 3986 URL validation on external links, strict Drive file-ID validation, and same-origin redirect enforcement on IPU portal sync.

Zero Telemetry

No analytics scripts, no behavioral tracking, no crash upload beacons, and no backend account required to use the desktop application.

Installation Guide

Install & verify in under a minute

Independent open-source installers are not code-signed with an EV certificate yet, so Windows SmartScreen may prompt on first run. Here is how to verify and install safely.

Windows (x64 NSIS Setup)

  1. 1 Download Semester_1.0.0_x64-setup.exe from the official GitHub Release above.
  2. 2 If Windows SmartScreen displays “Windows protected your PC”, click More info and choose Run anyway.
  3. 3 Complete the per-user setup (no administrator prompt needed). Optionally link your Google account in Settings → Data for automatic Drive AppData sync.
Get-FileHash "$env:USERPROFILE\Downloads\Semester_1.0.0_x64-setup.exe" -Algorithm SHA256

Android (Direct APK)

  1. 1 Download the latest Semester-v1.0.0-android.apk directly onto your Android device.
  2. 2 Open the downloaded APK and grant your browser or file manager permission under Install unknown apps when prompted.
  3. 3 Sign in with the same Google account you use on Desktop to pull your existing classes, timetable, and attendance history automatically.
